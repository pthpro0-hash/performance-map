# 전국 공연 지도 — 연극·뮤지컬

전국의 연극·뮤지컬 공연을 지도에서 한눈에 볼 수 있는 정적 웹페이지입니다.

**공개 주소:** https://pthpro0-hash.github.io/performance-map/

## 기능

- **지도 보기** — 축소하면 지역별 개수가 숫자로 뭉치고, 확대할수록 개별 공연으로 나뉩니다
  - 핀 색이 진행 상태(공연중 주황 · 예정 파랑 · 완료 회색), 이모지가 장르(🎭 연극 · 🎵 뮤지컬)입니다
- **기간 바로가기** — 오늘 · 이번주 · 이번달 · 전체
- **장르 필터** — 연극 · 뮤지컬
- **상태 필터** — 공연중 · 예정 · 완료 (완료된 공연은 기본으로 꺼져 있습니다. 칩을 누르면 켜집니다)
- **키워드 검색** — 공연명뿐 아니라 출연진 · 제작진 · 기획사 · 공연장 · 주소까지 검색합니다
  - 띄어쓰면 모두 포함 (`대학로 코미디`)
  - `-단어`는 제외 (`뮤지컬 -아동`)
  - 초성 검색 (`ㅁㅈㅋ` → 뮤지컬)
  - 검색어가 걸린 자리는 목록에서 노란색으로 표시됩니다
- **목록 보기** — 60건씩 끊어 보여주고 "더 보기"로 이어집니다. 정렬은 시작일·공연명·공연장 기준으로 바꿀 수 있습니다
- **공연 카드** — 포스터 · 기간 · 공연시간 · 러닝타임 · 관람연령 · 티켓가격 · 예매처 링크
  - "지도에서 보기"를 누르면 해당 공연 위치로 이동합니다
- 모바일 지원

## 데이터

[공연예술통합전산망(KOPIS)](https://www.kopis.or.kr) 오픈API입니다.

- 수집 범위는 실행 시점 기준 과거 2개월 ~ 미래 6개월, 연극과 뮤지컬입니다
- 공연장에 좌표가 없는 공연은 지도에 표시되지 않고 목록에만 나옵니다
- 갱신 시각은 페이지 상단에 표시됩니다

KOPIS는 예매가 등록된 공연을 기준으로 하므로, 예매처를 쓰지 않는 일부 소극장 공연은 포함되지 않을 수 있습니다.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 전체 (스타일·스크립트 포함) |
| `performances-data.js` | 지도용 공연 데이터 (자동 생성) |
| `.nojekyll` | GitHub Pages의 Jekyll 처리 비활성화 |

외부 라이브러리는 [Leaflet](https://leafletjs.com)과 [Leaflet.markercluster](https://github.com/Leaflet/Leaflet.markercluster), 지도 타일은 [OpenStreetMap](https://www.openstreetmap.org/copyright)을 사용합니다.
